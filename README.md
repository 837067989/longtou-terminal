# A股短线龙头战法监控终端

单文件、零外链、暗黑终端风的 A 股短线龙头战法决策面板（PWA 版）。

- 数据：2026-10-26（周一）盘中快照 · 13:10 实时
- 数据源：**easyquotation 0.7.7 · sina 通道 · 单一源**
- 页面轮询 `market_data.json` 热更新；核心池 10s、买点 5s 独立轮询

## 数据源说明

全部行情字段取自同一次 `market_snapshot`，同一时点、同一口径，不做跨源拼接。
页首「数据源对照表」可展开查看 17 个模块逐个的字段来源与派生方式。

| 性质 | 数量 | 含义 |
|---|---|---|
| 原生 | 4 | 直接读取 easyquotation 字段 |
| 派生 | 6 | 基于快照本地计算 |
| 历史累积 | 3 | 需跨日涨停名单回溯 |
| 替代口径 | 1 | 换指标近似（资金流） |
| 源外 | 2 | easyquotation 不提供（封板时间/开板次数） |
| 非行情 | 1 | 消息推送 |

关键判定口径：

- 涨停 = `now == high` 且 `ask1 == 0`
- 跌停 = `now == low` 且 `bid1 == 0`
- 封单额 = `bid1_volume × now`
- 涨跌家数 = 纯 A 股口径（不含北交所），2026-10-26 样本 5117 只

## 盘中能力

- **连板晋级率矩阵**：需两个交易日收盘归档后自动生成
- **核心池监控**：炸板/回封状态 + 事件日志，10s 轮询
- **主线捕捉**：6 类买点（封板排板 / 弱转强 / 放量突破 / 分歧低吸 / 冰点低吸 / 回封），经弱股关、身位关、炸板关、情绪关、方向关五道筛选
- **T+1 纪律**：所有卖出提示均为「明日开盘执行」，不出现当日卖出指令
