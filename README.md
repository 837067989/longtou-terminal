# A股短线龙头战法监控终端

单文件、零外链、暗黑终端风的 A 股短线龙头战法决策面板（PWA 版）。

- 数据：2026-10-26（周一）午盘快照 · 11:30 定格
- 数据源：**easyquotation 0.7.7 · sina 通道 · 单一源**
- 页面自动轮询 `market_data.json` 热更新；点「刷新」立即拉取

## 数据源说明

全部行情字段取自同一次 `market_snapshot`，同一时点、同一口径，不做跨源拼接。
页首「数据源对照表」可展开查看 17 个模块逐个的字段来源与派生方式。

| 性质 | 数量 | 含义 |
|---|---|---|
| 原生 | 4 | 直接读取 easyquotation 字段 |
| 派生 | 6 | 基于快照本地计算 |
| 历史累积 | 3 | 需跨日涨停名单回溯 |
| 替代口径 | 1 | 换指标近似（资金流） |
| 源外 | 2 | easyquotation 不提供（封板时间/开板次数） |
| 非行情 | 1 | 消息推送 |

关键判定口径：

- 涨停 = `now == high` 且 `ask1 == 0`
- 跌停 = `now == low` 且 `bid1 == 0`
- 封单额 = `bid1_volume × now`
- 涨跌家数 = 纯 A 股口径（不含北交所），2026-10-26 样本 5117 只

## 文件

- `index.html` — 单文件终端（含内嵌兜底数据）
- `market_data.json` — 外置热更新数据，与内嵌数据同构
- `manifest.json` / `sw.js` / `icon.svg` — PWA 支持
